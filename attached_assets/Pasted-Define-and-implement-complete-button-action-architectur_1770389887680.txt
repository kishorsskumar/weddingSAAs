1. START FREE TRIAL (Hero + Pricing + Final CTA)

Route to:
 /auth/signup

Flow:

1. User enters email
2. OTP verification
3. Auto-create new account
4. Auto-assign 14-day Growth plan trial
5. Create tenant workspace
6. Redirect to onboarding flow

Backend actions after successful signup:

• Create user record
• Create tenant record
• Assign plan = "trial_growth"
• Trial expiry = current_date + 14 days
• Create CRM lead entry with source = "Free Trial"

Also trigger:
Send WhatsApp notification to Super Admin:

Message:
"🎉 New Trial Signup – Atbott SaaS

Name: {{name}}
Email: {{email}}
Plan: 14-Day Growth Trial
Signup Time: {{timestamp}}"

Do NOT block user flow if WhatsApp fails.
